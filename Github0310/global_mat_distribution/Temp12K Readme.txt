Temp12K README

Files included:
01_temp12k_lipd_extract_temperature_series.py
02_temp12k_trend_mode_classification_6class_bin500_stablewin.py
03_fig1_map_and_mode_curves_3pattern.py

Run order:
1. 01_temp12k_lipd_extract_temperature_series.py
2. 02_temp12k_trend_mode_classification_6class_bin500_stablewin.py
3. 03_fig1_map_and_mode_curves_3pattern.py

Python version:
Python 3.10 or higher

Required packages:
numpy
pandas
openpyxl
matplotlib
cartopy

Install packages:
pip install numpy pandas openpyxl matplotlib cartopy

Input files for Script 01:
1. Temp12k LiPD files downloaded from:
https://www.ncei.noaa.gov/pub/data/paleo/reconstructions/climate12k/temperature/version1.0.0/
Use the files in:
Temp12k_directory_LiPD_files/

2. Temp12k_v1_essential_metadata_NOAA.xlsx

Place the LiPD files and Temp12k_v1_essential_metadata_NOAA.xlsx in the script directory, or place the script in that data folder and run it there.

Output of Script 01:
A Temp12k temperature summary workbook in .xlsx format

Input file for Script 02:
The .xlsx file generated by Script 01

Output of Script 02:
A classification output folder containing:
WCW
MHM
CCC
WWW
MIX
INSUF
and one SUMMARY.xlsx file

Input for Script 03:
The classification output generated by Script 02

Output of Script 03:
Fig1_AB_MapPlusCurves_3Pattern.png
Fig1_AB_MapPlusCurves_3Pattern.eps

Notes:
1. No absolute path is required.
2. All scripts use the script directory as the default input/output location.
3. Keep the scripts and required input files in the same working folder for stable reproduction.
